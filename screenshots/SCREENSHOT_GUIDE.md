## Quick Usage Tips

- **PPT**: Use UI screenshots for live demo slides, report diagrams for methodology/results slides
- **Report**: Include all screenshots with proper captions and figure numbers
- **Research Paper**: Use report diagrams (architecture, accuracy, confusion matrix) as main figures
- **Viva**: Keep UI screenshots ready for live walkthrough questions
